# MurasameRTSS 0.4.0

Android 性能监控浮窗与本地曲线记录工具，支持 Android 10 及以上，无需 Root；连接 Shizuku 可增强系统指标采集。

本版新增默认开启的“监控时自动记录”：开始监控即记录，停止监控即保存。记录期间采集全部已适配指标，不受浮窗显示选项限制。

15 项指标以类似 Afterburner 的网格曲线纵向展示，共用时间轴和同步游标，显示当前 / 选中读数及最低 / 最高 / 均值。保留单点、时间段和整次记录删除。

## 下载与升级

- 安装附件 `MurasameRTSS-0.4.0.apk`，可以直接覆盖旧版 PerfOverlay / MurasameRTSS，保留设置与记录。
- APK SHA-256：`8d83397fcbd8b168a8185c5ce15d0ab12671cdeba4120a676c91406b3337cb3f`。
- 允许悬浮窗和通知；需要应用 FPS 时，先启动 Shizuku 并授权本应用。
- 记录页可关闭自动记录；手动结束后，本次监控不会立刻续录。

## 验证与限制

- 5503 次本地断言通过，构建、签名与 APK 对齐检查通过。
- 已在 Android 16 手机上覆盖安装并确认版本，新的自动记录生命周期、多图界面与长时间性能仍需更多实机验证。
- GPU 频率受 ROM 权限约束；CPU / GPU 独立功耗尚未适配，充电时无法用电池净功率估算整机功耗。不可用项显示 `--`。
- 本地开发证书签名。源码不包含签名私钥；自行构建会使用自己的证书，不能直接覆盖本发布版。
