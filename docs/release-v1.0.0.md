# MurasameRTSS 1.0.0

Android 游戏性能监控浮窗与本地曲线记录，支持 Android 10 及以上。

## 本版更新 · 2026-10-10

- 新增 **日本語、English、Français、Deutsch**，保留简体中文。
- 在“关于 → 应用语言”选择语言；默认跟随系统，其他语言回退到英语。
- 翻译覆盖设置、通知、浮窗标签、曲线统计、删除确认、权限提示和历史更新。
- 删除首页副标题“把性能信息，留在屏幕边缘。”和关于页的图标制作说明。
- 调整导航及记录详情布局以容纳较长的外语文本；切换语言不会中断监控或记录。

## 下载与升级

下载附件 **MurasameRTSS-1.0.0.apk**。包名与签名保持一致，可覆盖安装此前发布的版本并保留设置和记录。附件提供 SHA-256 校验文件，源码可从本页 Source code 下载。

开启监控即可自动记录；可在“记录”页关闭自动记录。需要应用 FPS 时，先启动 Shizuku 并授权本应用。无需 Root。

## 已知限制

8425 次本地断言与资源、构建、签名检查通过，最终 APK 已覆盖安装。五语言主要页面、语言设置持久化及切换语言期间保持同一活动记录已通过实机检查；详情见仓库 `TEST_REPORT_1.0.0.md`。

GPU 频率受设备 ROM 权限约束，Shizuku 不能解除所有节点限制。CPU/GPU 独立功耗尚未适配。整机功耗仅在未接电源且放电时估算。原始硬件节点名和系统错误保留原文。第三方游戏、不同 ROM 和长时间负载仍需分别验证。

本地签名私钥不包含在源码中。自行构建使用其他签名时，不能覆盖本发布版。
